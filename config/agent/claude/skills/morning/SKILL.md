# morning

Use the user's timezone and current date. Inspect available connectors. Gather today's calendar, unanswered direct asks from the last two days, assigned due tasks, and concrete preparation for tomorrow's meetings.
Prioritize urgent asks, deadlines, preparation, and overdue replies. Include source links and times. Group mentions are lower priority unless the user is the bottleneck. Mark unavailable sources and inferred priority.
Lead with a short picture of the day and a few actionable items. Avoid invented motivational or mental-health claims. Sending replies and changing tasks require user authorization. Add action buttons only when requested and supported.
Optional visual output may use assets/fonts/fraunces-latin-600-normal.woff2; preserve its license.
