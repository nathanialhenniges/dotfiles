# codex-setup

Inventory current plugins, skills, config, and available tools. Read applicable global and repo rules.
Prefer built-in OpenAI capabilities, official vendor sources, and upstream community sources over personal duplicates. Inspect manifests; catalog presence does not prove vendor ownership.
Preserve unique custom skills and unrelated config. Verify replacement coverage before removal. Use supported plugin tools or the installed Codex CLI.
Install only requested capabilities. Installation does not authorize broader account access or prove authentication.
Validate config, installed state, frontmatter, and supporting paths. Explain new-chat requirements. Local skills require separate packaging/import for ChatGPT web; desktop tools may not run there.
