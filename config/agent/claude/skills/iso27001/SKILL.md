# iso27001

When the preserved workflow conflicts with this entrypoint or current user and environment rules, follow this entrypoint and the active rules.

Read workflow.md. Establish edition and organization scope before applying controls. Verify current official requirements.
Use references/annex-a-2022.md for 2022 controls, references/annex-a-2013.md for legacy assessments, and references/control-mapping.md for migration.
Separate implementation, documented intent, and absent evidence. Tie controls to risk assessment, ownership, measurable evidence, and the Statement of Applicability.
Report prioritized gaps. An agent review does not establish certification or auditor acceptance. Preserve existing documents outside requested scope.
