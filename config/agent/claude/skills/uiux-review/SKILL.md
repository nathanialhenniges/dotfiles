# uiux-review

When the preserved workflow conflicts with this entrypoint or current user and environment rules, follow this entrypoint and the active rules.

Read workflow.md for report format and references/nng-checklist.md for applicable heuristics.
Inspect actual screenshots, prototypes, or live UI with supported tools. State tested flows, devices, states, and interaction modes.
Use current primary sources for accessibility/platform requirements. Static screenshots do not prove unseen behavior.
Rate findings 0-4; report concrete trigger, impact, evidence, and practical fix. Prioritize blocking defects.
Review does not authorize redesign. Separate observed issues, hypotheses, and checks needing device/live access.
