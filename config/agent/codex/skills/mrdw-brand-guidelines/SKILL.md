# mrdw-brand-guidelines

MrDemonWolf is Nathanial Henniges's blue wolf identity. Core navy is #091533. Projects use #00ACED or #0FACED cyan; follow actual project tokens.
Inspect existing assets and design system. Reuse the official project or mrdemonwolf.com logo; do not generate or redraw logos.
Use wolf themes where appropriate. Keep client and Kommit branding separate; Kommit's own design system is authoritative.
Preserve exact user text, spelling, dimensions, colors, and anatomy. Check contrast and output geometry.
Do not apply Anthropic colors or typography as defaults. Included source license is attribution, not an official OpenAI endorsement.
