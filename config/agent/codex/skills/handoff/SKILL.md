# handoff

Read current conversation and workspace state. Lead with the next objective. Save a durable Markdown deliverable in the designated output directory or user-specified location.
Include context, decisions, completed work and actual checks, branch/worktree and dirty state, next steps, blockers, and exact reference paths or URLs. Reference existing specs and commits rather than duplicating them.
Redact credentials and unnecessary private data. Mark assumptions and unverified steps.
A handoff does not authorize archiving, moving worktrees, pushing, or messaging another chat. For a requested safe-to-archive handoff, inventory and durably preserve requested work before claiming safety.
