# consolidate-memory

Identify active memory rules and read relevant index entries and evidence. Group duplicates, flag contradictions, and preserve citations and dates. Do not convert past task instructions into permanent preferences.
For Codex managed memory, submit one small timestamped update note under ~/.codex/memories/extensions/ad_hoc/notes/. Describe proposed merges, removals, and corrections. Do not directly rewrite MEMORY.md, summaries, or rollouts.
Preserve private material. Report note submission separately from the memory system applying consolidation.
